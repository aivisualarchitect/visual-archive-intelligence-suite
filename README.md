# Visual Archive Intelligence Suite

Local-first Python toolkit for image archive analysis, OCR, metadata extraction, duplicate detection, folder audits, and HTML gallery review.

## Purpose

Visual Archive Intelligence Suite is a practical local workflow prototype for organizing, reviewing, and analyzing large image collections.

The project is designed for people who need to understand what is inside large visual archives without uploading private files to cloud services.

## What It Demonstrates

This repository is part of my applied AI and workflow-design portfolio. It demonstrates:

- Local-first automation
- Python scripting for practical workflow problems
- OCR-assisted image review
- Metadata and EXIF inspection
- Duplicate and near-duplicate detection concepts
- Image dimensions and orientation analysis
- Folder and file-path auditing
- HTML gallery/report generation
- Human-in-the-loop review design
- Privacy-aware technical architecture

## Planned Public-Safe Features

The public version is being prepared with sanitized demo data and simplified scripts.

Planned modules:

- Image inventory scanner

- Image size and orientation report
- HTML gallery generator
- Folder audit report
- Demo dataset and sample output

## Privacy-First Design

This project is intended to run locally.

No private image archive, personal dataset, client data, real user files, or sensitive metadata is included in this repository.

Public examples will use small demo files only.
