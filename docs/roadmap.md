# Roadmap

Visual Archive Intelligence Suite is being prepared as a public-safe portfolio repository.

The goal is to show practical local-first workflow design for image archive analysis, OCR, metadata review, duplicate detection, and human-in-the-loop review.

## Phase 5 — Future Enhancements

Possible future improvements:

- Near-duplicate detection

- Advanced filtering
- EXIF-focused review
- Batch review workflow
- Exportable evidence/report package

## Public Repository Boundary

This roadmap applies only to the public-safe version.

The repository will not include private archives, real personal image sets, client files, sensitive metadata, private ChatGPT exports, or identity-sensitive image collections.
