# Privacy-First Design

Visual Archive Intelligence Suite is designed as a local-first workflow.

The purpose of this project is to help users analyze, organize, and review image archives without uploading private files to cloud services.

## Privacy Principles

- Run analysis locally whenever possible.
- Do not include private image archives in the public repository.
- Do not include real personal datasets, client files, or sensitive metadata.
- Use small sanitized demo files for public examples.
- Keep human review in the workflow instead of relying only on automated output.

## Public Repository Boundary

This public repository is a portfolio-safe version.

It may include:

- simplified scripts
- sample folder structures
- sanitized demo data
- generated sample reports
- documentation
- screenshots that do not expose private information

It should not include:

- private images
- ChatGPT backup exports
- personal file paths
- real faces or identity-sensitive image sets
- passwords, API keys, or tokens
- client or employer data
